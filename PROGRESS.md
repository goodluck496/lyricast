# Bible multi-translation casting

## Цель

Добавить возможность выводить на странице кастинга Библии основной и дополнительный перевод одновременно.

## Принятый подход

- Не менять общий транспорт `createCastingFlow`: он уже пробрасывает payload между главным окном и окном кастинга.
- Расширить bible-store настройками дополнительного перевода и payload для кастинга.
- Загружать дополнительный перевод для той же книги/главы через существующий `BibleApiService`.
- Отображать дополнительный перевод отдельным блоком внутри текущего `BibleCastingComponent`.
- Начать с пресетов расположения, затем расширить до ручной позиции/размера.

## Исправления после первого запуска

- Убрана повторная инициализация Reveal при каждом старте кастинга.
- PrimeNG slider заменен на Angular Material slider.
- Layout дополнительного перевода переведен с flex на grid/overlay классы.
- Изменения layout/size дополнительного перевода форвардятся напрямую в casting window.
- Навигация использует уже загруженный `secondaryContent` из текущего casting process, без повторного запроса главы.
- При выборе дополнительного перевода текущая глава предзагружается в `bible-store.secondaryTranslationCache`.
- Кеш дополнительного перевода очищается только при отключении галки дополнительного перевода.
- Превью кастинга читает те же настройки и кеш дополнительного перевода, что и основное окно кастинга.
- Старт кастинга догружает дополнительный перевод перед `openCasting`, если кеш еще пустой.
- Стрелки в casting window переключают текущий стих локально по уже переданному `content` главы.
